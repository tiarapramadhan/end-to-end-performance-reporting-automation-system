# 📊 Sample Data

Repository ini menggunakan **dummy data** sebagai pengganti data operasional perusahaan.

Seluruh dataset pada folder ini dibuat khusus untuk keperluan demonstrasi, pengujian sistem, dan dokumentasi project sehingga tidak mengandung informasi internal maupun data sensitif.

---

# 📂 Contents

Folder ini akan berisi beberapa contoh dataset yang merepresentasikan struktur data asli.

| File | Description |
|------|-------------|
| `dummy-form-response.xlsx` | Contoh hasil response Google Form yang telah dianonimkan. |
| `dummy-dashboard.xlsx` | Contoh workbook yang digunakan untuk proses monitoring dan reporting. |

---

# 🔒 Data Privacy

Project ini dikembangkan berdasarkan studi kasus implementasi nyata pada lingkungan organisasi.

Untuk menjaga kerahasiaan informasi perusahaan:

- Seluruh data operasional telah diganti menggunakan **dummy data**.
- Tidak ada data karyawan, stakeholder, maupun informasi internal yang dipublikasikan.
- Struktur dataset tetap dipertahankan agar workflow automation dapat direplikasi tanpa mengungkap data asli.

---

# 📝 Notes

Dummy data memiliki struktur yang menyerupai implementasi sebenarnya sehingga seluruh proses automation, dokumentasi, dan demonstrasi sistem tetap dapat dipahami dengan baik tanpa menggunakan data produksi.
