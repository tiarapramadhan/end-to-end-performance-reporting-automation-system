# 📚 Documentation

Seluruh dokumentasi disediakan untuk membantu memahami alur sistem tanpa harus membaca keseluruhan source code.

---

# 📂 Contents

| File | Description |
|------|-------------|
| `workflow.pdf` | Dokumentasi alur kerja automation mulai dari Google Form hingga dashboard monitoring. |
| `dashboard.pdf` | Dokumentasi dashboard monitoring dan reporting yang digunakan oleh stakeholder. |
| `presentation.pdf` | Slide presentasi yang menjelaskan business context, architecture, implementation, dan hasil project. |
