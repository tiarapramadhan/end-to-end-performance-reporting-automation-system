# ⚙️ Automation

This folder contains the Google Apps Script source code used to automate the end-to-end reporting workflow.

The automation handles multiple operational processes triggered automatically after a report is submitted through Google Forms, including document management, calendar synchronization, email notifications, and reporting database updates.

---

## ✨ Automation Features

Current automation includes:

- Google Form submission trigger
- Duplicate submission prevention
- Dynamic form field mapping
- Google Calendar synchronization
- HTML email confirmation
- Automated Google Drive file organization
- Automatic file renaming
- Automatic folder creation
- Reporting status tracking
